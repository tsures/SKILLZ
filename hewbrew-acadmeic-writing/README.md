# הגהה לשונית וכתיבה אקדמית בעברית — סקיל

סקיל אחד לשני דברים: **הגהה ועריכה לשונית** של כל טקסט בעברית לפי כללי
האקדמיה ללשון העברית, ו**כתיבה אקדמית** בעברית תקנית בכל תחום דעת.
מנוע ההגהה עצמו נמצא בתוך הסקיל.

**הכול רץ מקומית.** אין מפתחות, אין שירות בתשלום ואין שליחת הטקסט שלך
לשירות חיצוני בזמן ההגהה. אותו טקסט מחזיר תמיד את אותם ממצאים, וכל ממצא
נושא את שם הכלל ואת מקורו — אפשר לחלוק עליו ולבדוק אותו.

## התקנה

אין בנייה ואין התקנת חבילות:

```bash
git clone https://github.com/mckova/hebrew-proofreading-academic-writing.git ~/.claude/skills/hebrew-proofreading-academic-writing
```

ב-Windows:

```powershell
git clone https://github.com/mckova/hebrew-proofreading-academic-writing.git "$env:USERPROFILE\.claude\skills\hebrew-proofreading-academic-writing"
```

לפרויקט אחד בלבד: `<הפרויקט>/.claude/skills/`.

נדרש **Node 18+** למנוע ההגהה, ו**Python 3** לבדיקת הניבים ולשליפת מקורות.
שניהם בלי חבילות נוספות. בלעדיהם הידע שבסקיל עובד, אך הבדיקות האוטומטיות לא.

## שימוש

אחרי ההתקנה אפשר לבקש בשפה חופשית מהאייג'נט המועדף עליכם להשתמש בסקיל להגהה, לניסוח אקדמי, לבדיקה של הטקסט וכד'.

את מנוע ההגהה אפשר להריץ גם ישירות:

```bash
node engine/dist/cli.js --register academic --file עבודה.txt   # הגהה
node engine/dist/cli.js --fix --file עבודה.txt                 # הטקסט המתוקן
```

```
בכדי לבדוק את התכנית , כתבתי שלוש מסמכים בשנת תשפה. היות ואין לי נסיון.
    ↓
כדי לבדוק את התוכנית, כתבתי שלושה מסמכים בשנת תשפ״ה. היות שאין לי ניסיון.
```

`--fix` מחיל רק תיקונים שיש להם תשובה אחת נכונה. מה שתלוי בהקשר — פסיק לפני
ו״ו החיבור, יידוע בסמיכות, החלפת מילה לועזית, הצעות סגנון — מדווח ונשאר
להכרעת הכותב. על Markdown, על קוד ועל טקסט שמביא דוגמאות שגויות בכוונה יש
להריץ בלי `--fix`: המנוע מגיה גם כתובות אינטרנט וגם את הדוגמה השגויה עצמה.
`--register academic` מפעיל 85 כללים, ובהם אורך משפט ומרשם עיוני;
`neutral` מפעיל 74, והוא המרשם לטקסט שאינו אקדמי.

| מה נבדק | דוגמאות |
|---|---|
| שגיאות נפוצות | בכדי, היות ו-, בגלל ש-, למרות ש-, במידה ו- |
| כתיב מלא | תכנית ← תוכנית, נסיון ← ניסיון, בטחון ← ביטחון |
| תחביר | התאם מין ומספר, יידוע בסמיכות, ״את״, מילות היחס של הפועל |
| פיסוק וטיפוגרפיה | פסיק, גרש וגרשיים, מקף עברי, מירכאות, אותיות סופיות |
| מספרים ותאריכים | שם המספר לפי מין שם העצם, שנים עבריות |
| מרשם וסגנון | אורך משפט, חזרות, שרשראות ״של״, קלישאות |

ולצד ההגהה: נטיית פועל בשבעת הבניינים, ניתוח צורה, סיווג שווא נע ונח, ניקוד
אותיות השימוש, מילות קישור לפי תפקיד, ניבים עם מגבלת ההקשר שלהם, ו-`heb_api.py`
לשאילתות למקורות — 403 החלטות האקדמיה, ניקוד מ-Dicta Nakdan ופסוקים מ-Sefaria,
בלי מפתח ובלי הרשמה, ובלי לשלוח את המסמך שאתה מגיה (`references/apis.md`).

## הידע שבסקיל

13 קובצי `references/`: רישום לשוני ומבנה טיעון, מילות קישור, פיסוק, מבנה
המשפט והסמיכות, ניבים, לשון תקנית, שיטות הפניה וביבליוגרפיה, ניקוד — ופרק
נפרד לכתיבה במדעי היהדות ובחקר המקרא.

## לקסיקונים אופציונליים

85 הכללים עובדים כמו שהם. מעליהם אפשר לבנות מקומית לקסיקונים מורחבים ישירות
מן האתר של האקדמיה — ~2,000 זוגות כתיב, 1,277 ניבים, 1,682 שמות יישובים ו־403
החלטות:

```bash
cd engine && npm install && npm run harvest
```

הפלט נשמר ב-`engine/data/` ואינו נכלל במאגר הזה: ל-`robots.txt` של האתר יש
`Content-Signal: ai-train=no, use=reference`. שום דבר כאן אינו מאמן מודל,
נאספות עובדות מילוניות בלבד, והפלט נשאר מקומי.

## התאמה אישית

`profile.md` בתיקיית העבודה — שיטת ההפניות, הרישום המועדף, מין הכותב והנחיות
המוסד; הסקיל מעדיף אותו על ברירות המחדל. `hebrew-editor.config.json` מכוון את
המנוע עצמו: כיבוי כללים, אורך משפט מרבי, מונחון בית ורשימת מילים מותרות.
תבנית: `engine/hebrew-editor.config.example.json`.
