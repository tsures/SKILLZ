## ב. שווא

**שווא נע** — במקורו, בתנועת היסוד, היה תנועה.

קיצורי דרך לזיהוי **שווא נע**:
- בראש מילה
- שני שוואים ברצף באמצע מילה — הראשון נח והשני נע

קיצורי דרך לזיהוי **שווא נח**:
- בכ"ף סופית (ך) — תמיד נח
- במילה "את" — התי"ו תמיד נח
- רצף שוואים בסוף מילה — שניהם נחים
- שווא שאינו בראש מילה בשם פועל — תמיד נח

## ג. דגש קל

- בא **רק** באותיות בג"ד כפ"ת.
- תפקידו להפוך עיצור מרופה לדגוש.
- בימינו ההבחנה נשמעת רק ב-בכ"פ; ב-גד"ת היא אינה נשמעת.

**מתי יש דגש קל:**
1. בראש מילה
2. אחרי שווא נח

בכל מצב אחר — אין סיבה לדגש קל.

## ד. אותיות השימוש: מש"ה וכל"ב

אותיות המתחברות למילה כדי לבטא יחס במשפט:

| האות | התפקיד | דוגמה |
|---|---|---|
| מ | מ' היחס (= מן) | מזיכרונם |
| ש | ש' הזיקה | שבאת |
| ה | ה' הידיעה | הירח |
| ו | ו' החיבור | והם |
| כ | כ' הדימוי | יפה כלבנה |
| ל | ל' היחס | לחדרי |
| ב | ב' היחס | בבית |

### ניקוד אותיות וכל"ב

**אין רצף שוואים בתחילת מילה בעברית.** מכאן תהליך **פירוק צרור שוואים**,
שממנו נגזרים רוב הכללים:

- ברירת המחדל: וכל"ב מנוקדות **בשווא נע**.
- ו' החיבור **בשורוק** לפני אותיות בומ"פ.
- ו' החיבור **בשורוק** לפני שווא — פירוק צרור שוואים.
- כל"ב **בחיריק** לפני שווא — פירוק צרור שוואים.
- וכל"ב לפני יו"ד שוואית — **חיריק מלא**, והיו"ד מאבדת את ניקודה.
- וכל"ב לפני חטף — **בתנועת החטף** (פירוק צרור שוואים).
- ו' החיבור לפני צירוף כבול יכולה להתנקד **בקמץ** להדגשת הצירוף
  (נוהג, לא כלל).
- כשכל"ב פוגשות את ה' הידיעה — הן מקבלות את ניקודה, **ה' הידיעה נבלעת**,
  והאות שאחריה מקבלת דגש משלים במידת הצורך.

### ניקוד אותיות מש"ה ודגש משלים

**כלל ראשי: אחרי אותיות מש"ה בא דגש משלים** — דגש המשלים את המילה
המקורית שהייתה לפני המילית.

- **אותיות גרוניות (אהח"ע ור') אינן מקבלות דגש.**
- מ' היחס — בחיריק, והאות שאחריה בדגש משלים.
- מ' היחס לפני גרונית — **בצירי** (תשלום דגש).
- ש' הזיקה — בסגול, והאות שאחריה בדגש משלים, אלא אם היא גרונית.
- ה' הידיעה — בפתח, והאות שאחריה בדגש משלים.
- ה' הידיעה לפני אר"ע — **בקמץ**.
- ה' הידיעה לפני ה"ח — **בפתח**.
- ה' הידיעה לפני חע"ה המנוקדות בקמץ ובהברה לא מוטעמת — **בסגול**.

## ו. בדיקה

```bash
python scripts/heb_api.py nikud "<טקסט>"
```

מחזיר ניקוד אוטומטי וחלופות מורפולוגיות. הפלט הוא הצעה ולא פסק —
בטקסט מקראי או משנאי יש להעדיף את נוסח המקור:

```bash
python scripts/heb_api.py verse "Numbers 21:9"
```

בהתלבטות על כלל: `python scripts/heb_api.py rules ניקוד`.
