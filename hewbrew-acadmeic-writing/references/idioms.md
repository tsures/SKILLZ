# ניבים וביטויים — המאגר ולולאת בדיקת ההקשר

ניב שגוי בצורתו קל לתפוס. ניב תקין בצורתו אך שגוי בהקשר קשה בהרבה, והוא
הפגם החמור יותר: הוא מסגיר שהכותב אינו יודע מה הביטוי אומר. המאגר בנוי כדי
לטפל בשניהם.

## המאגר

`references/idioms.tsv` — קובץ TSV, שבע עמודות:

| עמודה | תוכן |
|---|---|
| `type` | `ניב` · `ביטוי` · `הקשר` |
| `correct` | הצורה או הצורות התקינות, מופרדות ב-`;` |
| `wrong` | שיבושים מתועדים, מופרדים ב-`;` (יכול להיות ריק) |
| `meaning` | משמעות הביטוי |
| `context` | **מתי מותר להשתמש בו** — המגבלה הסמנטית |
| `example` | משפט אחד בשימוש תקין |
| `source` | מקור הביטוי או הכלל |

שלושת הסוגים:

- **`ניב`** (90) — ניב או פתגם קלאסי (`קרם עור וגידים`, `משענת קנה רצוץ`).
- **`ביטוי`** (23) — צירוף כבול או תבנית לשונית מודרנית (`כשלעצמו`, `נטל חלק`).
- **`הקשר`** (18) — מילה או צירוף **תקינים תמיד מבחינה דקדוקית, ומוגבלים סמנטית**.
  `לאור` הוא המקרה המובהק: הוא נושא גוון חיובי, ולכן `לאור העלייה בתאונות`
  שגוי אף שאין בו שום שגיאת דקדוק. הצורה הנכונה: `בעקבות`, `נוכח`, `עקב`.
  לקבוצה זו שייכים גם `זכה ל-`, `נהנה מ-`, `סבל מ-`, `תרם ל-`, `בזכות`,
  `גרר אחריו`, `חף מפשע`, `מנת חלקו`, `הוכיח` (רק להוכחה מלאה), `הפריך`,
  `טען` (רומז שהדבר שנוי במחלוקת), `הודה` (גוון של הודאה באשמה),
  `ניצל` (גוון של ניצול לרעה), `לכאורה` (מחייב המשך).

## שלוש רמות הזיהוי

הכלי מסווג כל ממצא לאחת משלוש רמות, ולכל רמה יחס שונה:

| רמה | מה זה | מה עושים |
|---|---|---|
| **שגיאה ודאית** | הצורה מופיעה ברשימת השיבושים | לתקן. אין שיקול דעת. |
| **חשד לשיבוש** | רוב מילות הניב נמצאות אך לא כולן | לבדוק — ייתכן שיבוש שאינו במאגר, וייתכן צירוף אחר לגמרי |
| **בדיקת הקשר** | הצורה תקינה לחלוטין | **כאן נמצאת העבודה** — ראו הלולאה |

## לולאת בדיקת ההקשר

```bash
python scripts/heb_api.py idioms <קובץ>
```

הכלי מוצא את הביטויים ומגיש לכל אחד את משמעותו ואת מגבלת ההקשר שלו. הוא
אינו יכול להכריע אם השימוש מוצדק — זו הכרעה סמנטית. הלולאה:

1. **הרצה.** הכלי מדפיס לכל ממצא: המשפט המלא · הביטוי · המשמעות ·
   `מתי מתאים` · דוגמה תקינה.
2. **הכרעה, ממצא-ממצא.** על כל פריט ברשימת בדיקת ההקשר יש לענות על שלוש
   שאלות, לפי הסדר:
   - **האם המשמעות היא הכוונה?** להציב את `meaning` במקום הביטוי במשפט.
     אם המשפט משנה את משמעותו — הביטוי שגוי.
   - **האם המגבלה ב-`context` מתקיימת?** זה השדה שתופס את `לאור`,
     את `זרה מלח על פצעיו` בלי פצע קודם, ואת `מתי מעט` על חפצים.
   - **האם הרישום מתאים?** ניב עממי (`לא דובים ולא יער`, `כקליפת השום`)
     בטקסט אקדמי פורמלי — לרוב לא.
3. **תיקון או הסרה.** אם התשובה לאחת השאלות שלילית: להחליף בניסוח ישיר.
   ניב אינו חובה. משפט בלי ניב עדיף על ניב במקום הלא נכון.
4. **הרצה חוזרת** עד שכל פריט ברשימה עבר הכרעה מודעת.

הלולאה אינה מסתיימת כשהרשימה מתרוקנת — היא מסתיימת כשכל פריט **נבדק**.
ביטוי שנשאר במקומו לאחר בדיקה הוא תוצאה תקינה של הלולאה.

## שליפה נקודתית

```bash
python scripts/heb_api.py idiom "עור וגידים"
python scripts/heb_api.py idiom "לאור"
```

חיפוש בצורה התקינה, בשיבושים ובמשמעות. לשימוש **לפני** הכתיבה, כשיש התלבטות.

## איך ההתאמה עובדת

- ניקוד, פיסוק ואותיות סופיות מנורמלים לפני ההשוואה, ולכן `רָקְמָה` ו-`רקמה`
  נתפסות זו כזו.
- צירוף בן שתי מילים ומעלה מותאם בסובלנות לנטיות: תחילית (`ו`, `ב`, `ה`…)
  וסיומת (`ה`, `ים`, `ות`, `תי`…). כך `רקם עור וגידים` תופס גם
  `רקמה עור וגידים`.
- צירוף בן מילה אחת (`באם`, `ברת`, `לאור`) מותאם **בדיוק מלא** עם גבולות מילה.
  בלי זה `ברת` נתפסת בתוך `ברית` ו-`באם` בתוך `מובאות`.
- מילית יחס בת אות אחת בסוף הצירוף (`עשה שימוש ב-`) נדרשת כתחילית של המילה
  הבאה, ולא כמילה נפרדת.

המאגר מונה **131 ערכים**, 74 מהם עם שיבוש מתועד. מקורו ברשימת 230 הניבים
של הקורס, בגיליונות השיבושים ובתרגילי תיקוני הלשון.

בבדיקה על שלוש עבודות אקדמיות אמיתיות: **אפס התרעות שווא** ברמת השגיאה
הוודאית (הממצא היחיד — `לקח חלק` — אמיתי). על טקסט בדיקה עם שמונה שיבושים
מכוונים: שישה נתפסו כשגיאה ודאית והשניים הנותרים עלו לבדיקת הקשר.

## הרחבת המאגר

שורה חדשה = שבעה שדות מופרדים בטאב. אין להשתמש בטאב בתוך שדה. שדות
`correct` ו-`wrong` מקבלים כמה חלופות מופרדות ב-`;`.

לפני הוספת ערך יש לוודא שלושה דברים: שהצורה התקינה מאומתת מול מקור
(מילון, האקדמיה ללשון, `heb_api.py rules`); ששדה `context` מנוסח כמגבלה
ולא כהסבר כללי — הוא הבסיס ללולאה; ושהדוגמה היא משפט אקדמי אמיתי.

לערך מסוג `הקשר` יש לנסח את `context` תמיד בשני חלקים: מה הגוון הסמנטי,
ומה החלופה כשההקשר הפוך.
