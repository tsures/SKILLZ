# הגהה לשונית וכתיבה אקדמית בעברית

סקיל זה עושה שני דברים: מגיה טקסט בעברית לפי כללי האקדמיה ללשון העברית,
ומגדיר איך נראה טקסט אקדמי תקין — רישום לשוני, מבנה טיעון, מילות קישור,
פיסוק, מבנה המשפט, ניבים והפניות. ההגהה חלה על כל טקסט בעברית; הכללים
האקדמיים אינם תלויים בתחום — התוכן משתנה, הכללים לא.

ההגהה עצמה נעשית במנוע מקומי שבתוך הסקיל (`engine/`): 85 כללים, ללא רשת
וללא התקנה — רק Node 18 ומעלה.

> כל הנתיבים שלהלן יחסיים לתיקיית הסקיל עצמה.

## הגהה של טקסט קיים

כשהבקשה היא להגיה, לערוך או לבדוק טקסט — זה סדר העבודה:

```bash
node engine/dist/cli.js --register academic --file <קובץ>   # תקן, פיסוק, תחביר וסגנון
python scripts/heb_api.py idioms <קובץ>                     # ניבים: צורה + התאמה להקשר
```

עוברים ממצא־ממצא; כל ממצא נושא את שם הכלל ואת מקורו, ואפשר לחלוק עליו.
`--fix` מחיל רק את התיקונים שיש להם תשובה אחת נכונה, ומה שתלוי בהקשר נשאר
להכרעת הכותב. בטקסט שאינו אקדמי יש להשתמש ב-`--register neutral`, שאינו
מפעיל את כללי המרשם העיוני.

**בדיקה אחת אינה אוטומטית: כל מופע של `, ו`.** המנוע תופס רשימה של שלושה
איברים ומעלה, אך רשימה של שני איברים אינה נבדלת במכונה ממשפט מאוחה — שתיהן
״X, וY״, והכלל בהן הפוך. לכן בכל מופע יש להכריע בקריאה: שני צירופי שם באותו
תפקיד — רשימה, והפסיק יורד; נושא ונשוא בכל אחד משני האיברים — משפט מאוחה,
והפסיק נשאר. `references/punctuation.md`.

בספק לשוני — לא לנחש. לשאול את האקדמיה ללשון:

```bash
python scripts/heb_api.py rules פיסוק
```

## כתיבה של טקסט חדש

1. **לפני הניסוח** — `references/style.md` (רישום ודפוסי ניסוח),
   `references/structure.md` (מבנה לפי סוג הטקסט) ו-`references/argument-text.md`
   (שלד הטיעון וסוגי ההצדקות).
2. **בזמן הכתיבה** — `references/connectives.md` לקישור בין הטענות,
   `references/citations.md` לכל הפניה.
3. **אחרי הכתיבה — שתי בדיקות חובה:** שתי הפקודות שלמעלה. הראשונה מתוקנת
   ממצא־ממצא; השנייה מפעילה את **לולאת בדיקת ההקשר** — ראו
   `references/idioms.md`; זו אינה בדיקה אוטומטית אלא הכרעה סמנטית על כל פריט.

## כללי ברזל

- **רישום אחיד לאורך כל הטקסט.** שלושה רישומים לגיטימיים, ואין לערבב:
  - **גוף ראשון יחיד** — "אבחן", "אעסוק", "ראיתי לנכון". מדעי הרוח, עבודה יחידנית.
  - **ניסוח סתמי** — "ניתן לראות", "נראה כי". מדעי החברה והטבע.
  - **גוף ראשון רבים** — רק בעבודה שנכתבה בידי כמה מחברים. בעבודה יחידנית
    זו שגיאת רישום.
- **הבחנה חדה בין ידע לפרשנות.** טענה מן המחקר → הערת שוליים. ניתוח עצמאי →
  מסומן במפורש ("להבנתי", "לדעתי") וללא הערה. השניים לא מתערבבים במשפט אחד.
- **סובייקט מדויק.** כל טענה מיוחסת לטוען שלה: "המחבר", "החוקרת", "הנתונים מלמדים" —
  לא "הספר אומר".
- **מבנה טיעון קבוע:** טענה → עדות עם הפניה → פירוק העדות → השוואה או
  הנגדה → מסקנה.
- **כל איבר שני במשפט מאוחה מקבל מילת קישור**, וכל פסקה נפתחת בקישור
  לקודמתה. `references/connectives.md` מחזיק את רשימת הקשרים המלאה:
  פסוקיות תיאור, פסוקיות לוואי/מושא/נושא/נשוא, ששת קשרי המשפט המאוחה
  ועשרים קטגוריות של קישור בין פסקאות.
- **הצדקה אינה הסבר.** הסבר עונה על *מה?* ועל *איך?*; הצדקה עונה על *מדוע
  הטענה נכונה?*. `references/argument-text.md`.
- **ניב נכנס רק אם הוא מדויק בצורתו ומתאים בהקשרו.** ניב במקום הלא נכון
  גרוע ממשפט בלי ניב.

## המנוע המקומי — `engine/`

הגהה מלאה בלי רשת, בלי מפתחות ובלי התקנה. דורש Node 18 ומעלה בלבד.
אותו טקסט מחזיר תמיד את אותם ממצאים, וכל ממצא נושא את שם הכלל ואת מקורו.

| פקודה | מה היא עושה |
|---|---|
| `node engine/dist/cli.js --register academic --file <קובץ>` | הגהה מלאה: שגיאות נפוצות, כתיב מלא, התאם מין ומספר, יידוע בסמיכות, מילות היחס של הפועל, פיסוק, טיפוגרפיה, מספרים ותאריכים, מרשם אקדמי וסגנון |
| `node engine/dist/cli.js --register academic "<טקסט>"` | אותה הגהה על טקסט ישיר, בלי קובץ |
| `node engine/dist/cli.js --fix --file <קובץ>` | מחזיר את הטקסט לאחר התיקונים החד-משמעיים בלבד |
| `node engine/dist/cli.js --conjugate <שורש> --binyan <בניין> [--nikud]` | נטיית פועל מלאה. בניינים: פעל, נפעל, פיעל, פועל, הפעיל, הופעל, התפעל |
| `node engine/dist/cli.js --lexicon` | אילו לקסיקונים אופציונליים טעונים בפועל |

**התיקונים שמוחלים ב-`--fix`:** כתיב מלא, התאם מין בשם המספר, מיליות שעבוד, פיסוק
ורווחים, גרש וגרשיים, אותיות סופיות ועתיד מדבר. מה שתלוי בהקשר — נקודה בסוף
משפט, סימן שאלה, פסיק לפני ו״ו החיבור, יידוע בסמיכות, החלפת מילה לועזית
בחלופה עברית וכל הצעות הסגנון — מדווח בנפרד ונשאר להכרעת הכותב.

**אין להריץ `--fix` על Markdown, על קוד או על טקסט שמביא דוגמאות שגויות
בכוונה.** המנוע מגיה כל מה שנראה לו כעברית, ולכן יתקן גם כתובת אינטרנט,
גם מה שבתוך בלוק קוד וגם את הדוגמה השגויה עצמה. על טקסטים כאלה יש להריץ
את ההגהה בלי `--fix`, ולהכריע ממצא־ממצא.

**המרשם:** `academic` מפעיל 85 כללים, ובהם אורך משפט, מרשם עיוני וסגנון;
`neutral` מפעיל 74, והוא המרשם לטקסט שאינו אקדמי.

**ניקוד רק לפי בקשה.** הפלט המורפולוגי מחזיר כתיב מלא כברירת מחדל;
`--nikud` מחזיר צורות מנוקדות. גזרה שאין לה תבנית ייעודית מסומנת
`approx` ואינה מחזירה ניקוד שגוי בשקט.

## שירותים חינמיים (ללא מפתח וללא הרשמה)

`scripts/heb_api.py`. תיעוד מלא ודוגמאות `curl` ב-`references/apis.md`.

| פקודה | מה היא עושה | מקור |
|---|---|---|
| `idioms <קובץ>` | ניבים: שיבושי צורה + רשימת פריטים לבדיקת הקשר | מקומי |
| `idiom "<ביטוי>"` | שליפת ערך: צורה תקינה, משמעות, מגבלת הקשר, דוגמה | מקומי |
| `rules <מונח>` | חיפוש ב-403 החלטות רשמיות בלשון ובפיסוק | האקדמיה ללשון העברית |
| `topics` | פרקי ההחלטות (קמץ, משקלים, שימושי לשון, פיסוק…) | האקדמיה ללשון העברית |
| `nikud "<טקסט>"` | ניקוד אוטומטי + חלופות מורפולוגיות | Dicta Nakdan |
| `verse <הפניה>` | נוסח מקראי או תלמודי מדויק עם ניקוד וטעמים | Sefaria |
| `lint <קובץ>` | בדיקת לשון מקומית — גיבוי בלבד, כשאין Node | מקומי |

> LanguageTool אינו תומך בעברית (62 שפות, עברית אינה ביניהן) — אין טעם לנסות.

## התאמה אישית (רשות)

אם קיים בתיקיית העבודה קובץ `profile.md`, יש לקרוא אותו ולתת לו עדיפות על
ברירות המחדל כאן: שיטת ההפניות הנדרשת, רישום מועדף, מין הכותב לצורך התאמה
דקדוקית, הנחיות עיצוב של המוסד ומונחון קבוע.

אם המשתמש מספק עבודות קודמות שלו ומבקש כתיבה "בסגנון שלי" — יש לקרוא אותן,
לחלץ את דפוסי הניסוח החוזרים ולכתוב אותם ל-`profile.md` לפני תחילת הניסוח.

את המנוע עצמו אפשר לכוון בקובץ `hebrew-editor.config.json` בתיקיית העבודה:
מרשם ברירת מחדל, כיבוי כללים, אורך משפט מרבי, מונחון בית (`terms`), תוספות
כתיב מלא ורשימת מילים מותרות (`allowWords`) לשמות ולמונחי תחום. תבנית:
`engine/hebrew-editor.config.example.json`.
